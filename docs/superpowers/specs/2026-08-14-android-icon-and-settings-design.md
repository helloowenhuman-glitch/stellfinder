# Android 아이콘 및 설정 버튼 디자인

## 목표

Stellfinder Android 앱을 홈 화면에서 쉽게 알아볼 수 있게 만들고, 상단 설정 진입 버튼을 글자 대신 직관적인 톱니 아이콘으로 바꾼다.

## 런처 아이콘

- 짙은 남색의 둥근 사각형 배경을 사용한다.
- 참고 이미지의 파스텔 분홍·하늘색 그라데이션과 파란 외곽선을 유지한, 얼굴 없는 네 꼭짓점 별을 오른쪽 위에 크게 배치한다.
- 왼쪽 아래에는 별을 향하는 간결한 연보라색 망원경 실루엣 하나를 배치한다.
- 작은 별, 점, 광선, 글자, 표정, 복잡한 입체 장식은 넣지 않는다.
- 작은 홈 화면 크기에서도 별과 망원경이 분명히 구분되는 단순한 구성을 우선한다.

## 설정 버튼

- 기존의 `설정` 텍스트 버튼을 제거한다.
- 제공받은 참고 이미지와 같은 연한 회보라색 톱니 형태 및 흰색 중앙 원형 구멍을 사용한다.
- 버튼에는 접근성을 위한 `설정` 설명을 유지한다.
- 버튼을 누르는 동작과 링크 열기 방식 선택 기능은 바꾸지 않는다.

## 일정 알림

- 첫 실행에서 링크 열기 방식을 정한 뒤, 일정 알림 설정을 차례로 안내한다.
- 첫 화면 제목은 `알림을 받을 일정 종류를 선택하세요`이고, 제목 아래에 `복수 선택 가능`을 표시한다.
- 일정 종류 선택 항목은 공연, 굿즈, 콜라보, 오프라인이다.
- 두 번째 화면 제목은 `알림을 받을 때를 선택하세요`이고, 제목 아래에 `복수 선택 가능`을 표시한다.
- 알림 시점 선택 항목은 7일 전, 5일 전, 3일 전, 1일 전, 당일이다.
- Android 시스템 알림 권한은 두 선택을 마친 뒤 요청한다.
- 앱은 공식 검증 일정 중 사용자가 선택한 종류만 하루에 한 번 확인하고, 선택한 시점에만 알림을 한 번 보낸다.
- 설정 톱니에서 링크 열기 방식과 알림 종류·시점을 모두 다시 변경할 수 있다.
- 네트워크 오류는 사용자에게 경고하지 않고 다음 확인 때 재시도한다.

## 검증

- 설정 버튼이 글자 대신 아이콘 전용으로 구성되고 접근성 설명을 유지하는지 단위 테스트로 확인한다.
- 알림 선택값의 저장·복원, 선택 종류·시점의 매칭, 중복 알림 방지를 단위 테스트로 확인한다.
- Android 단위 테스트와 디버그 APK 빌드를 수행한다.
- 웹 프로젝트의 lint, 테스트, build를 함께 수행한다.
